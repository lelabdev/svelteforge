# PRD — SvelteForge Monorepo

## Summary

SvelteForge is a `sv` community addon monorepo that scaffolds normal SvelteKit projects with production-ready foundations powered by Skeleton UI v5 and Tailwind CSS v4.

The boilerplate stays intentionally generic: it provides a complete, coherent Skeleton theme and reusable application foundations without pre-inventing product-specific visual abstractions.

## Architecture

```
svelteforge/                     ← monorepo root (bun workspaces)
├── packages/
│   ├── svforge/                 ← base addon (UI kit + layouts + theme)
│   │   ├── templates/
│   │   │   ├── base/            ← Base mode (UI only)
│   │   │   └── dashboard/       ← Dashboard mode (base + auth + admin + DB)
│   │   ├── src/
│   │   │   ├── index.ts         ← defineAddon() entry point
│   │   │   ├── modes/           ← base.ts, dashboard.ts
│   │   │   └── templates.ts     ← AUTO-GENERATED by prebuild
│   │   └── scripts/prebuild.ts  ← embeds template files as strings
│   ├── ui_toast/
│   ├── dnd/
│   ├── tiptap/
│   └── graph/
```

## CSS foundation

A generated project keeps the global styling surface minimal:

```text
src/routes/layout.css
  = single global CSS entrypoint / framework wiring

src/lib/styles/svelteforge-theme.css
  = complete Skeleton v5 theme / visual source of truth
```

There is no generic `tokens.css` or `index.css` styling layer in the base scaffold. Standard Tailwind utilities handle local layout/whitespace. A consumer project can introduce an additional project-specific layer later if a concrete repeated requirement is not covered by Skeleton/Tailwind.

## Templates

| Template | Description |
|----------|-------------|
| `base` | UI kit + layouts + forms + complete Skeleton v5 theme |
| `dashboard` | Base + admin dashboard + Better Auth + Drizzle ORM |

## Modules

Each module is an independent npm package installable via `sv add`.

| Package | What it adds |
|---------|-------------|
| `svforge` | Base: essential UI + SEO + layouts + theme |
| `@svforge/ui_toast` | Toast notifications |
| `@svforge/dnd` | Drag & drop sortable lists |
| `@svforge/tiptap` | Rich text editor |
| `@svforge/graph` | Knowledge graph visualization |

## Install

```bash
npx sv create my-app --template minimal --types ts --add 'svforge=template:base' --install bun
```
